# รู้ทัน-ไม่ตกเป็นเหยื่อภัยไซเบอร์

เว็บไซต์ที่มุ่งให้ความรู้และเผยแพร่ข้อมูลเตือนภัยออนไลน์ เพื่อช่วยให้ประชาชนรู้เท่าทันกลโกงและมิจฉาชีพในโลกดิจิทัล พร้อมเปิดช่องทางให้ผู้ใช้งานส่งข้อมูลเบาะแสเกี่ยวกับเหตุการณ์หรือช่องทางที่อาจเกี่ยวข้องกับมิจฉาชีพ

**Website: https://ruetan-ma-catspeare-itna-fawn.vercel.app/**

## Features

- เผยแพร่ข้อมูลข่าวสารและคำเตือนเกี่ยวกับภัยออนไลน์
- ให้ความรู้เกี่ยวกับกลโกงและวิธีป้องกันตนเองจากมิจฉาชีพ
- เปิดช่องทางให้ผู้ใช้งานส่งข้อมูลเบาะแสที่เกี่ยวข้องกับภัยออนไลน์
- แสดงข้อมูลเกี่ยวกับเว็บไซต์ นโยบายความเป็นส่วนตัว และเงื่อนไขการใช้งาน

## ระบบ Auto X (ปิดการทำงานอยู่)

โปรเจกต์มีสคริปต์สำหรับช่วยสร้างและเผยแพร่โพสต์ภาษาไทยบน X โดยซอร์สโค้ดอยู่ที่ [auto-x-script-setup](https://github.com/maneekongritphichayaporn-creator/auto-x-script-setup) ระบบทำงานคร่าว ๆ ดังนี้:

1. ใช้ GitHub Actions เรียกสคริปต์เมื่อสั่งรัน workflow ด้วยตนเอง
2. เลือกหัวข้อตามวันในประเทศไทย เช่น เทคโนโลยี AI ภัยไซเบอร์ กลโกง และกฎหมายดิจิทัล
3. ใช้ OpenRouter ช่วยสร้างข้อความภาษาไทย แล้วส่งโพสต์ไปยัง X ผ่าน X API

ปัจจุบันระบบนี้ปิดการทำงานและยังไม่เชื่อมต่อกับเว็บไซต์นี้ จึงไม่มีการสร้างหรือเผยแพร่โพสต์จากเว็บไซต์ในขณะนี้ ทั้งนี้ workflow ในซอร์สโค้ดต้องสั่งรันเอง และแต่ละครั้งที่รันจะเผยแพร่โพสต์จริงบนบัญชี X ที่ตั้งค่าไว้

## Getting Started

### Prerequisites

ติดตั้ง Node.js และ npm ก่อนเริ่มใช้งาน

### Installation

1. เปิด Terminal หรือ Command Prompt
2. เข้าไปยังโฟลเดอร์เว็บไซต์

```bash
cd web
```

3. ติดตั้ง dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

เปิด URL ที่แสดงใน Terminal เพื่อเข้าใช้งานเว็บไซต์ โดยทั่วไป Vite จะใช้ `http://localhost:5173`

### Build for Production

```bash
npm run build
```

คำสั่งนี้จะสร้างไฟล์สำหรับ production ตามการตั้งค่าของโปรเจกต์

## Important Notes

- โฟลเดอร์ `node_modules/` สามารถสร้างใหม่ได้ด้วย `npm install`
- โฟลเดอร์ `build/` หรือ `dist/` เป็นไฟล์ผลลัพธ์จากการ build และไม่จำเป็นต้องเก็บใน Git หากสามารถสร้างใหม่ได้
- ควรเก็บ `package.json` และ `package-lock.json` ไว้เพื่อให้ติดตั้ง dependencies ได้อย่างถูกต้อง
- ห้ามเผยแพร่ API keys, passwords, tokens หรือข้อมูลลับลงใน repository
